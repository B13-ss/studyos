# StudyOS PWA

This is the installable Progressive Web App version of StudyOS.

## Install on Android
1. Put this folder on a web host (GitHub Pages, Netlify, Vercel, etc.).
2. Open the HTTPS site in Chrome on Android.
3. Chrome menu → Add to home screen / Install app.
4. Launch StudyOS from the home screen.

The service worker enables offline caching after the first successful visit.
User study data remains in browser localStorage unless a backend is added.
